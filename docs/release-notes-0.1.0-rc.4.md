# AgentProof 0.1.0-rc.4

AgentProof 0.1.0-rc.4 is the package-readiness release candidate for the existing verified repository-patch workflow. It preserves the RC3 action, Receipt V2, authority boundaries, correlation contract, CLI/SDK API, and state model.

This candidate adds the authorized Apache-2.0 package licence, verified public npm metadata, and executable CLI packaging. It does not activate production integration or add a new action or product surface.

Node.js 22.5 or newer is required. The package is ESM-only and assumes a local platform with Node.js filesystem, subprocess, SQLite, and Git support.
