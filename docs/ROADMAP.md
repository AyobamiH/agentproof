# Evidence-led roadmap

1. **Standalone public prerelease — complete.** RC6 is published on GitHub and npm from merged source `a0ee17a70d05bc3c339c0c15be6bb38b4517771a`. GitHub, staged, and registry tarballs match byte-for-byte; maintainer 2FA approval, clean registry installation, package exports, schemas, CLI, and registry signature passed. The trusted GitHub workflow has stage-only authority. See [RC6 registry reconciliation](evidence/npm-rc6-registry-reconciliation.md).
2. **Ten independent agent installations — active.** Measure first receipt, blockers, assistance, trust comprehension, and intent to integrate. [Collection tooling](adoption/README.md) is implemented; automated engineering runs do not count as independent participants.
3. **Verified repository-change usage.** Measure successful actions, duplicate prevention, false-success detection, verification latency, compensation, and recovery.
4. **Adoption repairs.** Fix documentation, packaging, portability, and protocol ambiguity demonstrated by those installations.
5. **Production authority and signing provider.** Add an explicit production provider without weakening development/production separation. The [provider prerequisite contract](protocols/production-provider-readiness.md), explicit [Vault signer and external approval clients](protocols/production-provider-adapters.md), and adapter outage recovery tests are in place in unreleased source. The [bounded production repository-patch canary](evidence/hosted-production-canary-acceptance-20261017.md) passed 17/17 exact-source live checks with separate Cloudflare approval/signing secrets, immutable GitHub OIDC identity, durable replay/recovery and authenticated compensation. This is software custody and one disposable workload, not HSM custody, a generic provider or DoneState release authority.
6. **One evidence-demanded action.** DoneState selected `agentproof.release.v1` for its first additional consequence candidate. A [source-only exact GitHub draft prerelease contract](actions/release-v1-candidate.md) now exercises durable one-mutation intent, provider readback and a separate signed release receipt. No production release, restricted signing service, independent OpsTruth release verifier, or DoneState action is enabled. Do not activate until the independent authority, global fencing, real disposable canary and verifier gates pass.
7. **Wider integrations.** Add protocol or platform adapters after adoption is repeatable.

Not active: dashboards, payments, a generic marketplace, a broad agent operating system, a connector catalogue, an unrelated MCP directory, or speculative action types. Reconsider only with recorded adoption or buyer evidence.
