# AgentProof 0.1.0-rc.6

RC6 keeps the proven `agentproof.repository_patch.v1` transaction and Receipt
V2 trust boundary unchanged while finishing the standalone product boundary
needed for real external consumption.

## Included

- public CLI and SDK for the bounded repository-patch lifecycle;
- transaction-bound development approval and single-use nonce semantics;
- durable exactly-once execution and correlation-bound reconciliation;
- independent repository-state verification;
- signed Receipt V2 evidence and offline verification;
- authenticated compensation successors;
- reproducible exact-commit Git package installation;
- repository CI and documentation-closure checks;
- canonical project vision and packaged AgentProof skill;
- candidate DoneState lifecycle-adapter contracts for future merge, deployment,
  and release receipts;
- guarded GitHub prerelease creation;
- documented first-package npm staging plus a stage-only OIDC lane for later
  releases.

## Not included

RC6 does not provide production authority or a KMS/HSM signer, an OS-enforced
executor sandbox, a hosted coordinator, remote action routing, merge/deploy/release
execution, payments, or general availability.

The only enabled consequential action remains
`agentproof.repository_patch.v1`.
