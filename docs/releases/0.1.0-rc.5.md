# AgentProof 0.1.0-rc.5

RC5 makes AgentProof’s standalone repository the intended canonical portable-product source while preserving the RC4 repository-patch action, Receipt V2, correlation contract, CLI/SDK, schemas, state model, fixtures, and Apache-2.0 licence.

It adds product-direction authority and package metadata for `AyobamiH/agentproof`. OpenClaw Operator becomes a package consumer and approval/task adapter. No new action or production activation is included.

Node.js 22.5 or newer is required. The package is ESM-only and assumes Git plus a local filesystem on Linux, macOS, or WSL2. Native Windows is not validated.
